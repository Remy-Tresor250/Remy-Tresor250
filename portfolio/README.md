# Remy Tresor — interactive portfolio

An eight-chapter, scroll-driven 3D story built with React Three Fiber, custom GLSL and a
generative Web Audio score.

| Chapter | What happens |
| --- | --- |
| 00 Intro | 64k particles assemble into a holographic portrait sampled from a real photo |
| 01 Rewind | A VHS-era 1985 frame dissolves into today while the date stamp counts up |
| 02 Manifesto | Scroll-scrubbed manifesto, WebGL photographs that bend with scroll velocity |
| 03 Kigali | The particles become Africa; a beam of light rises from Rwanda; SVG ridgelines draw the thousand hills |
| 04 Work | Pinned horizontal gallery of nine products — WebGL frames, video loops on focus, a live 3D Land Cruiser for Tujyane |
| 05 Elements | The cloud becomes an atom, orbited by the stack |
| 06 Recognition | TICON Africa Startup of the Year 2025 (Libblio), Bee open source |
| 07 Contact | The cloud becomes a living globe |

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build into dist/
```

## How it is put together

- `src/three/StoryParticles.tsx` + `shaders/particles.ts` — one particle system, six shapes
  (portrait · africa · data field · atom · galaxy · sphere) blended in the vertex shader.
- `src/lib/world.ts` — sections declare `data-world` anchors; the cloud interpolates between them as you scroll.
- `src/three/GLImages.tsx` — photos and project frames rendered in WebGL but positioned by the DOM
  (VHS/dissolve, paper bend, RGB split, reveal wipes, hover ripples, video textures).
- `src/lib/audio.ts` — a calm generative ambient score (pads, sparkles, air) synthesised live; it opens up while you scroll.
- `src/data/projects.ts` / `src/data/profile.ts` — all copy and links.

## Assets

- `public/img` — portraits (background removal + retouching done offline).
- `public/media/frames` — art-directed project frames and 8s loops, rendered from
  `scripts/frames/index.html` with `node scripts/render-frames.mjs <assets-dir>`.
- `public/models/landcruiser.glb` — Tujyane's Land Cruiser, meshopt-compressed (4 MB → 0.6 MB).
- `public/data/africa.json` — generated by `npm run gen:points` from Natural Earth (world-atlas).

## Performance

Particle budget and DPR adapt to the device (`src/lib/device.ts`, drei `PerformanceMonitor`), post-processing
drops on weak GPUs, the 3D model and videos load lazily, and the WebGL bundle is split from the page.
